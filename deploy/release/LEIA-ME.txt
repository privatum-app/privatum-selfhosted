PRIVATUM - instalação simples
=============================

Sem auditoria externa. Leia os limites em docs/THREAT-MODEL.md no projeto.

1. Instale o Docker:
   - Windows e macOS: Docker Desktop (https://docs.docker.com/desktop/)
   - Linux: Docker Engine com o plugin Compose (https://docs.docker.com/engine/install/)

2. Dê dois cliques no atalho do seu sistema:
   - Windows: iniciar.bat
   - macOS:   iniciar.command  (na primeira vez: botão direito > Abrir, porque o
              macOS bloqueia scripts baixados da internet)
   - Linux:   iniciar.sh       (ou, no terminal: ./iniciar.sh)

   Na primeira vez ele baixa as imagens do Privatum (cerca de 200 MB). No fim,
   abre no seu navegador o painel da instância (http://127.0.0.1:8099), que
   só funciona neste computador. Crie a senha do painel e copie o endereço .onion.

3. Abra esse endereço no Tor Browser (https://www.torproject.org/download/),
   no nível de segurança Standard. Crie sua identidade e envie o seu convite.

Para parar: parar.bat / parar.command / parar.sh. Seus dados e o endereço .onion
são mantidos. A instância só fica no ar com o computador ligado e o Docker rodando.

IMPORTANTE: o endereço .onion vem de uma chave guardada no Docker (volume
privatum_tor-state). Faça backup dela; veja docs/OPERATIONS.md no projeto.
